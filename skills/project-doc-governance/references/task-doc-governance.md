# 任务过程文档治理

更新时间：2026-08-16

当用户要求管理大任务、大阶段、专项迁移、调研过程、阶段性决策或过程文档命名时，读取本文件。

## 建立独立文件夹的条件

满足任一条件时，在 `docs/tasks/` 下为该任务或阶段建立独立文件夹：

- 工作跨越多个模块、组件、服务或文档域。
- 任务包含明确阶段，例如调研、方案、实施、验证、复盘。
- 需要保留中间决策、约束、风险、验证记录或交接上下文。
- 任务预计会持续多轮对话、多人协作或后续回访。
- 过程材料如果写入架构或工程事实源，会污染稳定知识。

小型一次性修改不建任务文件夹；若产生可复用结论，直接写入对应事实源。

## 两级索引

- **热索引** `docs/tasks/README.md`：只列进行中 + 最近已完成任务，每任务固定一行（日期、名称、状态、稳定结论位置）。大小恒定，是默认读取路径的一部分。
- **冷索引** `docs/tasks/archive/README.md`：已归档任务列表，仅显式追溯时读取。

归档触发条件（满足任一）：

- 任务收口且结论提升完成 → 立即归档。
- 兜底：任务完成超 90 天必须归档。

## 推荐目录结构

```text
docs/tasks/2026-08-16-task-name/
  README.md
  2026-08-16-plan.md
  2026-08-16-research.md
  2026-08-16-decisions.md
  2026-08-16-verification.md
  2026-08-16-retrospective.md
```

按需创建文件，不为形式补齐空文档。第三方技能（如 writing-plans）的产物按产物类型归入对应文件：计划→plan.md、决策→decisions.md、验证→verification.md、复盘→retrospective.md。若某阶段很大，可建二级阶段目录 `2026-08-16-phase-api/`。

## 文件职责

- `README.md`：任务入口、范围、状态、阶段索引、稳定结论位置。
- `日期-plan.md`：目标、范围、分阶段计划、验收标准。
- `日期-research.md`：调研素材、官方文档最小结论、版本或方案比较。
- `日期-decisions.md`：过程中的决策快照、原因、影响范围、回滚条件。
- `日期-verification.md`：构建、测试、手工验证、截图或日志摘要。
- `日期-retrospective.md`：复盘、可复用经验、后续待办。

## 只追加，不改写

过程文件是历史快照：决策变更时追加新节并标注“取代 D1 决策”，绝不回改历史。过程记录与最终落地不一致是正常属性，不是需要修复的问题。

## 收口流程

任务结束或阶段收口时按顺序执行：

1. **前置检查**：所有可复用结论是否已提升到事实源？未提升的先提升。
   - 稳定架构事实 → `docs/architecture/`；工程流程 → `docs/engineering/`；
     业务规则 → `docs/product/`；部署运维 → `docs/operations/`；
     文档规则 → `docs/governance/`。
   - 稳定决策（不可逆、影响边界、含真实权衡）写成 ADR 进 `docs/decisions/`，
     规则见 `adr-governance.md`。
2. 任务目录 README 记录“稳定结论位置”，列出每条结论对应的事实源或 ADR 链接。
3. 整个任务目录移入 `docs/tasks/archive/`，从热索引移除该行（或改为指向 archive 的一行摘要）。

## 防误读四道防线

1. **独立路径**：归档任务在 `tasks/archive/`，不在默认读取顺序内。
2. **警告横幅**：归档任务 README 顶部加横幅——“历史过程记录，非事实源。最终结论位置：……”。
3. **单向指针**：归档文档指向事实源；事实源不回链归档。
4. **AGENTS.md 声明**：archive 仅用于显式追溯，引用其内容前必须先以事实源核对。

## 读取优先级

事实源 → tasks 热区（接续进行中任务，或事实源无答案时）→ archive（仅显式追溯）。

治本原则：agent 频繁翻找过程文档是事实源残缺的症状，应补提升结论，而不是限制读取。

## 命名规则

- 文件名：`YYYY-MM-DD-name.md`；目录名：`YYYY-MM-DD-name/`。
- `name` 使用英文小写、数字和连字符；仓库若已有中文命名规范，可保持一致。
- 同一天同类文档需要区分时，在名称后增加职责词，例如 `2026-08-16-research-map-sdk.md`。
- `README.md` 固定作为入口，不使用日期前缀。
